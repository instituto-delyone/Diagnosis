# ECG Tests

Os testes iniciais validam:
- conversões do papel;
- cálculos de frequência;
- QTc;
- limites quantitativos explicitamente fornecidos pelo Medeletro;
- identificação estrutural de derivações e componentes.

A etapa seguinte deve adicionar testes com traçados sintéticos e imagens de ECG, sempre com referência explícita à fonte e ao caso de validação.
