# ECG Engine

Camada inicial do motor ECG do Diagnosis/JACKNOSIS.

Responsabilidades:
1. receber um registro ECG estruturado;
2. validar velocidade e ganho;
3. calcular medidas básicas;
4. aplicar regras de conhecimento separadas;
5. devolver observações estruturadas.

Este primeiro núcleo não pretende substituir interpretação médica nem contém um classificador de doenças.
